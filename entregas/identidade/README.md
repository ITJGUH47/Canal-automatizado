# Identidade visual — Papiro Revela

Artes geradas para o canal, na linguagem de colagem editorial: papel envelhecido, tinta escura, laranja, dourado e verde-petróleo. O pergaminho com luz é o símbolo comum às duas peças.

## Banner do YouTube

**[Baixar banner](./papiro-revela-banner-youtube.jpg?raw=true)**

- JPEG, **2560 × 1440 pixels**, aproximadamente **655 KB**, abaixo do limite de 6 MB.
- Nome, símbolo e frase ficam no centro, dentro da área segura de 1546 × 423 pixels, para acomodar o recorte dos diferentes dispositivos.
- No YouTube Studio, abra **Personalização → Perfil → Imagem do banner → Enviar**. Selecione este JPEG e confira a prévia do recorte antes de publicar.

## Foto de perfil — TikTok, Instagram e YouTube

**[Baixar foto de perfil](./papiro-revela-perfil.png?raw=true)**

- PNG, **1080 × 1080 pixels**, aproximadamente **2,8 MB**, abaixo de 4 MB.
- Use o mesmo arquivo nas três redes para manter o canal reconhecível.
- No TikTok e Instagram, abra **Editar perfil → Alterar foto** e centralize o símbolo na prévia circular.
- No YouTube Studio, use **Foto → Enviar**.

Os originais foram criados por geração de imagem; as versões finais foram exportadas nas dimensões indicadas. Nome do canal: Papiro Revela. Frase: “Curiosidades bíblicas, direto do texto.”

Se o GitHub abrir a página da imagem, use **Download raw file**. Nenhuma imagem foi aplicada ou publicada automaticamente nas contas das redes sociais.
